# Blog Pessoal

Um blog desenvolvido com Python e Flask, permitindo criar, editar, excluir e pesquisar posts.

## Funcionalidades

- Sistema de login
- Criação de posts
- Edição e exclusão
- Pesquisa
- Paginação
- Datas automáticas
- Página 404 personalizada
- Proteção de rotas
- Senhas criptografadas

## Tecnologias

- Python
- Flask
- SQLite
- HTML
- CSS
- Jinja2
